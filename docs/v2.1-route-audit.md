# DarkLight Events V2.1 route audit

| Route/komponent | Aktiv brug før V2.1 | Beslutning |
| --- | --- | --- |
| `/competition/events` | Databasebaseret EventOS-oversigt | Beholdes som eneste primære eventadministration |
| `/competition/events/[id]` | Event Command Center | Beholdes som eventets samlede administration |
| `/competition/control-center` | Global driftsovervågning | Beholdes; ingen parallel eventredigering tilføjes |
| `/competition/admin` | Global system-, FAQ- og regeladministration samt indlejret sponsorpanel | Beholdes som global EventOS-side; sponsoradministration flyttes til `/competition/sponsors` |
| `/competition/sponsors` | Fandtes ikke | Ny kanonisk global sponsoradministration med eksisterende `Sponsor`-model |
| `/competition/leaderboard` | Dublerede offentlig ranglistequery og opfandt point ved manglende point | Redirectes til `/rangliste` |
| `/competition/hall-of-fame` | Dublerede manuel Hall of Fame-visning | Redirectes til resultatdrevet `/hall-of-fame` |
| `/competition/control-center/tournaments` | Dublerede disciplinlisten uden administration | Redirectes til `/competition/disciplines` |
| `/gallery` | Hardcoded galleri fra `data/gallery.ts` | Redirectes til databasebaseret `/galleri` |
| `/staff` | Hardcoded staff fra `data/staff.ts` | Redirectes til databasebaseret `/team` |
| `AdminLiveDataPanel` | Ingen aktive imports; localStorage-baseret legacy-administration | Slettet |
| `GalleryCard`, `data/gallery.ts`, `data/staff.ts` | Kun brugt af erstattede hardcodede sider | Slettet |

Øvrige Control Center-, VehicleOS-, resultats-, heat- og bracket-routes beholdes, fordi de fortsat har aktive imports eller fungerer som globale driftsvisninger/kompatibilitetsroutes.

## Bevarede statiske kilder

`data/events-log.ts`, `data/documents.ts`, `data/news.ts`, `data/permissions.ts`, `data/results.ts` og `data/drivers.ts` indeholder fortsat V1-/demoindhold. De er ikke slettet i denne etape, fordi flere globale driftssider stadig importerer dem; at fjerne dem uden tilsvarende databasemodeller ville fjerne funktionalitet. `data/faq.ts`, kontakttekster og Footer omtaler stifterne som kontakt-/virksomhedsoplysninger og er ikke Team-kort. De kan senere flyttes til en generel indholdsmodel.
